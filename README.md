# 🧠 Autocorrect Tool (Python + Colab)
This project is an AI-based Autocorrect Tool built using Python and the `pyspellchecker` library.  
It corrects spelling mistakes in sentences and paragraphs and includes a custom dictionary for better accuracy.
### 🔤 Example Usage

Input: the thrd line also hav misstakes

Output: the third line also have mistakes
